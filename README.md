## 🔧 Setup & Installation

### Requirements:
```
Python 3.9+
PostgreSQL 13+
Redis (optional, for caching)
```

### Environment Variables:
```env
DISCORD_TOKEN=your_bot_token
DATABASE_URL=postgresql://user:pass@host:port/db
PLAYER_DATABASE_URL=postgresql://user:pass@host:port/players_db
REDIS_URL=redis://localhost:6379 (optional)
```

### Installation:
```bash
# Clone repo
git clone https://github.com/yourusername/fut-trader-bot
cd fut-trader-bot

# Install dependencies
pip install -r requirements.txt

# Set up database
python setup_db.py

# Run bot
python bot.py
```
