# Railway Deployment Guide - FUT Hub

Complete guide for deploying both backend and frontend to Railway.

## 🗄️ Database Service (PostgreSQL)

Railway will automatically provision PostgreSQL. These variables are **auto-generated**:

```
DATABASE_URL (auto-generated by Railway)
PGHOST (auto-generated)
PGPORT (auto-generated)
PGDATABASE (auto-generated)
PGUSER (auto-generated)
PGPASSWORD (auto-generated)
```

**Action Required:**
1. Add PostgreSQL service to your Railway project
2. Connect to it and run the schema:
   ```bash
   # Copy the DATABASE_URL from Railway
   # Then run locally:
   psql [DATABASE_URL] < web-platform/database/schema.sql
   ```

## 🔧 Backend Service Environment Variables

### Required Variables (YOU MUST SET)

#### 1. Application Config
```env
NODE_ENV=production
PORT=3001
FRONTEND_URL=https://your-frontend.up.railway.app
```
- **NODE_ENV**: Set to `production`
- **PORT**: Railway will inject `$PORT`, but 3001 is default
- **FRONTEND_URL**: You'll get this URL after deploying frontend (update later)

#### 2. Database Connection
Railway provides `DATABASE_URL`, but our app uses individual variables:

```env
DB_HOST=${{PGHOST}}
DB_PORT=${{PGPORT}}
DB_NAME=${{PGDATABASE}}
DB_USER=${{PGUSER}}
DB_PASSWORD=${{PGPASSWORD}}
```

**In Railway Dashboard:**
- Click "Variables" tab
- Add each variable above
- Use the `${{VARIABLE}}` syntax to reference Railway's auto-generated vars

Alternatively, use DATABASE_URL directly:
```env
DATABASE_URL=${{DATABASE_URL}}
```
(Then modify backend code to parse DATABASE_URL)

#### 3. Discord OAuth (Required for Login)
```env
DISCORD_CLIENT_ID=your_discord_client_id_here
DISCORD_CLIENT_SECRET=your_discord_client_secret_here
DISCORD_REDIRECT_URI=https://your-backend.up.railway.app/api/auth/discord/callback
```

**How to Get Discord Credentials:**
1. Go to https://discord.com/developers/applications
2. Click "New Application"
3. Name it "FUT Hub" (or your preferred name)
4. Go to "OAuth2" section
5. Copy **Client ID** → use as `DISCORD_CLIENT_ID`
6. Click "Reset Secret" → copy it → use as `DISCORD_CLIENT_SECRET`
7. Add Redirect URL: `https://your-backend-url.up.railway.app/api/auth/discord/callback`
8. Save changes

**Note:** Update `DISCORD_REDIRECT_URI` after you get your backend URL from Railway

#### 4. JWT Secret (Required for Auth)
```env
JWT_SECRET=your_random_secret_key_here_make_it_long_and_random
```

**Generate a secure secret:**
```bash
# Option 1: OpenSSL
openssl rand -base64 32

# Option 2: Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"

# Option 3: Just use a long random string
# Example: mY$uP3r$3cR3t!JWT#K3y@2025!R4nD0m#Str1ng
```

#### 5. Stripe (Required for Payments)
```env
STRIPE_SECRET_KEY=sk_live_your_stripe_secret_key
STRIPE_WEBHOOK_SECRET=whsec_your_webhook_secret
STRIPE_PLATFORM_FEE_PERCENTAGE=25
```

**How to Get Stripe Credentials:**
1. Go to https://stripe.com
2. Create account or sign in
3. Go to Developers → API Keys
4. Copy "Secret key" → use as `STRIPE_SECRET_KEY`
5. For testing, use "Test mode" keys (starts with `sk_test_`)
6. For webhooks:
   - Go to Developers → Webhooks
   - Add endpoint: `https://your-backend.up.railway.app/api/stripe/webhook`
   - Copy "Signing secret" → use as `STRIPE_WEBHOOK_SECRET`

**Test Mode (Recommended for Launch):**
```env
STRIPE_SECRET_KEY=sk_test_51xxxxxxxxxxxxx
STRIPE_WEBHOOK_SECRET=whsec_test_xxxxxxxxxxxxx
STRIPE_PLATFORM_FEE_PERCENTAGE=25
```

### Optional Variables (Can Skip for MVP)

#### 6. AWS S3 (For Image Uploads)
```env
AWS_ACCESS_KEY_ID=your_aws_access_key
AWS_SECRET_ACCESS_KEY=your_aws_secret_key
AWS_BUCKET_NAME=fut-hub-uploads
AWS_REGION=us-east-1
```

**Can Skip:** Image uploads won't work, but platform will function

#### 7. Redis (For Caching)
```env
REDIS_URL=redis://default:password@redis.railway.internal:6379
```

**Can Skip:** App will work without caching

## 🎨 Frontend Service Environment Variables

### Required Variables

```env
NEXT_PUBLIC_API_URL=https://your-backend.up.railway.app
```

**IMPORTANT:**
- Must be the **full URL** of your backend service
- Must start with `https://`
- Must NOT have trailing slash
- Example: `https://backend-production-a1b2.up.railway.app`

**You'll get this URL after deploying backend first**

## 📝 Complete Railway Setup Steps

### Step 1: Create Railway Project
1. Go to https://railway.app
2. Sign up/login with GitHub
3. Click "New Project"
4. Choose "Deploy from GitHub repo"
5. Select `simonhayes51/fut-trader-bot`

### Step 2: Add PostgreSQL Database
1. In your project, click "New"
2. Select "Database" → "Add PostgreSQL"
3. Wait for provisioning
4. Click on PostgreSQL service → "Variables" tab
5. Copy `DATABASE_URL` for later

### Step 3: Deploy Backend
1. Click "New" → "GitHub Repo"
2. Select your repo again
3. Click "Settings" → "Root Directory"
4. Set to: `web-platform/backend`
5. Go to "Variables" tab
6. Add these variables:

```env
# Application
NODE_ENV=production
PORT=3001
FRONTEND_URL=https://TEMP_WILL_UPDATE_LATER

# Database (Reference PostgreSQL service)
DB_HOST=${{PGHOST}}
DB_PORT=${{PGPORT}}
DB_NAME=${{PGDATABASE}}
DB_USER=${{PGUSER}}
DB_PASSWORD=${{PGPASSWORD}}

# Discord OAuth (Get from Discord Developer Portal)
DISCORD_CLIENT_ID=your_client_id
DISCORD_CLIENT_SECRET=your_client_secret
DISCORD_REDIRECT_URI=https://TEMP_WILL_UPDATE_LATER/api/auth/discord/callback

# JWT (Generate random string)
JWT_SECRET=your_super_secret_jwt_key_make_it_long_and_random

# Stripe (Get from Stripe Dashboard - USE TEST MODE)
STRIPE_SECRET_KEY=sk_test_your_test_key
STRIPE_WEBHOOK_SECRET=whsec_test_your_webhook_secret
STRIPE_PLATFORM_FEE_PERCENTAGE=25
```

7. Click "Deploy"
8. Wait for deployment
9. Copy the backend URL (e.g., `https://backend-production-a1b2.up.railway.app`)

### Step 4: Initialize Database
1. Connect to your Railway PostgreSQL:
```bash
# Get DATABASE_URL from Railway PostgreSQL service
psql [paste_database_url_here] < web-platform/database/schema.sql
```

Or use Railway's web interface:
1. Click PostgreSQL service
2. Click "Data" tab
3. Use query editor to paste schema

### Step 5: Update Backend Variables
Now that you have the backend URL:

1. Go to Discord Developer Portal
2. Update OAuth2 Redirect URL to: `https://your-backend-url.up.railway.app/api/auth/discord/callback`
3. Go to Railway Backend service → Variables
4. Update `DISCORD_REDIRECT_URI` to your real backend URL + `/api/auth/discord/callback`
5. Keep `FRONTEND_URL` as temp for now

### Step 6: Deploy Frontend
1. In Railway project, click "New" → "GitHub Repo"
2. Select your repo
3. Click "Settings" → "Root Directory"
4. Set to: `web-platform/frontend`
5. Go to "Variables" tab
6. Add this ONE variable:

```env
NEXT_PUBLIC_API_URL=https://your-backend-url.up.railway.app
```

7. Click "Deploy"
8. Wait for deployment
9. Copy the frontend URL (e.g., `https://frontend-production-c3d4.up.railway.app`)

### Step 7: Final Backend Update
1. Go to Backend service → Variables
2. Update `FRONTEND_URL` to your real frontend URL
3. Redeploy backend if needed

### Step 8: Update Discord OAuth
1. Go to Discord Developer Portal → Your App → OAuth2
2. Add Redirect URL: `https://your-frontend-url.up.railway.app/api/auth/callback`
3. Add to "Allowed Origins" if needed

## 🚨 Troubleshooting

### Backend Won't Start
- Check Railway logs
- Verify database connection variables
- Make sure `schema.sql` was executed

### Frontend Shows 404
- Check if Next.js build succeeded
- Verify `web-platform/frontend` is set as root directory
- Check build logs for errors

### API Calls Fail
- Check `NEXT_PUBLIC_API_URL` is set correctly
- Check backend is running (visit backend URL + `/health`)
- Check CORS settings in backend (`FRONTEND_URL` must match)

### Discord Login Fails
- Verify `DISCORD_CLIENT_ID` and `DISCORD_CLIENT_SECRET`
- Check Discord OAuth redirect URIs are correct
- Check `DISCORD_REDIRECT_URI` matches backend URL

### Database Errors
- Verify schema was executed
- Check database variables are correct
- Check Railway PostgreSQL is running
